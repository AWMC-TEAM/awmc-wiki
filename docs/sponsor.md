# ☕ 赞助支持 AWMC

AWMC 的全部服务由社区成员利用业余时间维护，**不接受任何形式的强制收费**，所有核心功能永久免费开放。

维持这些服务需要真实的成本。如果 AWMC 曾帮到你 —— 帮你查到一次成绩、帮你避开一次白跑，或者只是陪你在群里水了一会儿 —— 欢迎请我们喝杯咖啡。

你的每一分赞助，都能看到它去了哪里。

| 服务 | 说明 |

## 钱花在哪里

赞助收入主要流向两个方向：**让服务活着**，以及**把善意传出去**。

| 支出项 | 说明 |
| --- | --- |
| 🖥️ 服务器 | 承载 Bot、API、数据库与状态监控 |
| 🌐 域名与证书 | 各服务域名的年度续费与 SSL 证书 |
| 📡 监控节点 | 状态站的多线路探测节点（上海移动 / 电信 / 联通） |
| 🚀 CDN 与带宽 | 静态资源分发、谱面与图片加速 |
| 🔧 第三方服务 | 对象存储、图像识别等按量计费接口 |
| 💛 公益捐赠 | 赞助收入的一部分，用于回馈社会，记录见 [AWMC 公益板块](https://bbs.wmc.pub/forums/awmc.16/) |

::: tip 成本公示
根据 AWMC BBS [赞助名单帖](https://awmc.cc/threads/91/post-267) 的公示，维持服务稳定运行需要 **¥1650.00 CNY**。

具体的收支明细与定期公示，请以论坛原帖为准。
:::

## 🤖 在 Bot 里查看赞助榜

在 AWMC Bot 中发送：

```text
赞助
```

别名：`赞助榜`、`本月赞助`。

Bot 会读取爱发电开放数据，生成**当前自然月**的赞助榜，展示本月赞助者的昵称与排名
（🥇 / 🥈 / 🥉），金额默认隐藏，避免公开攀比。管理员可通过 `BREAK配置 sponsor_show_amount 1`
开启金额显示。

::: tip 说明
赞助榜来自爱发电公开订单数据，只统计当月已成功的赞助记录；没有数据时 Bot 会提示
「本月还没有公开赞助记录～」。
:::

::: warning 赞助后想留名？
由于订单较多，赞助后如果需要出现在赞助名单中，请**携带爱发电订单号**在 [AWMC BBS 赞助名单帖](https://awmc.cc/threads/91/post-267) 下回复。
:::
