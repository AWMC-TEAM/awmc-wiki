# 交流群群规

::: tip 一句话
AWMC x RankHub 交流群是围绕 **舞萌 DX** 与 **AWMC / RankHub** 服务的交流空间。
为了让大家聊得舒服、也让服务走得长远，请花两分钟看看下面的约定喵～
:::

本页适用于下列全部官方交流群，以及 AWMC Bot 所在的其他群聊。**进群即视为已阅读并同意本页内容。**

::: info 群规修改恕不另行通知
本页规则可能根据实际情况随时调整，**修改恕不另行通知**，恕不逐一告知；请以本页当前内容为准，
继续留在群内即视为接受最新版本。
:::

::: danger 禁止机器人入群，发现即踢（不另行警告）
**全部官方交流群一律禁止任何第三方机器人加入**，包括但不限于：

- 用 **OneBot / NapCat / SL（Shamrock、Lagrange 等）** 等框架或协议端自建的 Bot；
- 各类**签到、推送、抽奖、点歌、AI 聊天**类现成 Bot；
- 群友自己部署、以「拉个 Bot 玩玩」为名义拉进群的任何机器人；
- 用**小号伪装成机器人**、或给机器人挂上人类昵称混进来的。

**一经发现直接踢出**，不提醒、不宽限、不解释。想继续用请自己部署到**私群**，
不要在官方群内保留。

**AWMC Bot 本身、以及管理团队统一维护的官方 Bot 不在此列。**

几个判定要点：

- 以「是否为一个自动回复的机器人账号」为准，不看它自称什么；
- 拉 Bot 进群的人负责在 Bot 被移出后清掉残留（如欢迎语、定时消息），
  长期留着不管的按**广告**追加处理；
- 同一个 Bot 被踢后**反复拉回**，拉人者按第六节升级处理；
- 只发几条消息就「潜水」的 Bot 同样算，不因「它还没说话」而放过。
:::

## 二、相互尊重

- 文明发言。**禁止**辱骂、人身攻击、威胁、歧视、地域黑、挂人、人肉搜索等行为。
- **禁止辱骂、谩骂机器人、管理层、项目制作人或负责人；此类行为将导致永久封号。**
- 观点不同很正常，请就事论事，不要针对个人；不要在群里追着人对线。
- 不拿他人的隐私、外貌、身份玩梗，也不开让人不适的玩笑。
- **禁止冒充**官方、管理员、Bot 或他人身份发布信息。

### 群昵称规范

群昵称应**可正常识别与称呼**。禁止使用下列类型的昵称：

| 类型 | 说明 |
| --- | --- |
| `OPENID` 及同类标识 | 平台内部标识、Bot 返回的 `OPENID`、`Ref_ID`、Token 等无实义编号 |
| 乱码与不可见字符 | 乱码字符串、无意义字符堆、纯空白昵称、零宽字符等用于隐藏身份的昵称 |
| 伪装 Bot 或官方 | 冒充 Bot、管理员、群主、官方团队的名称及其近似写法（如 `AWMC`、`Bot`、`管理员` 等身份性名称） |
| 冒充他人 | 使用他人昵称、头像或身份特征，足以使人误认 |

管理员有权要求修改不合规昵称；**经提醒后仍未修改的**，按第六节处理。

::: danger 禁止跨群挂人与断章取义转发（永久拉黑）
**禁止**将群内聊天记录（含群主、管理员、Bot 管理员及群成员的发言）以**断章取义**的方式
截图、转发或搬运至其他群聊及平台，用于公开指责、引导舆论、挑起争端或实施报复。

**禁止**在其他群聊或平台针对群成员的发言进行**公开辱骂、嘲讽、指名攻击**或组织围攻。

违反本条者，**一经发现即永久拉黑**，不另行警告。以下情形均不构成免责事由：以玩笑为名、
以私下分享为名、或以未预见后果为名的转发与传播。

群内讨论应在群内解决。确需向管理团队反映的，请通过**私聊**提交并附完整上下文，
不得散播截图片段。
:::

## 三、理性交流

- 鼓励积极解答他人的问题，但**没有人有义务必须回答**。
- 问题长时间无人回应时，请先检查表述是否清晰、是否提供了足够的背景信息
  （平台、版本、报错原文、复现步骤等）。信息越具体，越容易被解答。
- 求助前请先看[帮助文档](/guide/introduction)与[指令帮助](/guide/bot/advanced)，
  文档里已经写明的问题，请勿反复刷屏追问。
- 遇到 Bug、账号异常、数据错误或功能建议，请到[论坛](https://bbs.wmc.pub/forums/awmc-bot.17/)发帖，
  而不是在群里 @ 群主或管理团队。
- 请勿长时间刷与主题无关的话题。

::: warning 遇到问题请去论坛发帖，不要 @ 群主或管理团队
群主与管理团队**不是客服**。遇到 Bug、账号异常、数据错误、功能建议等问题，请先查
[帮助文档](/guide/introduction)与[指令帮助](/guide/bot/advanced)；仍然解决不了的，
请到**论坛**发帖提问：

👉 **[AWMC Bot 版块 · bbs.wmc.pub/forums/awmc-bot.17](https://bbs.wmc.pub/forums/awmc-bot.17/)**

发帖时请写清问题描述、复现步骤，并附上 Bot 返回的 `Ref_ID`，方便定位。
在群里反复 @ 群主、管理或 Bot 管理员催问，或以私聊方式无端骚扰管理团队与群成员，
都属于**骚扰行为**：轻则提醒，重则**禁言 1 日**，屡犯按第六节升级处理。
:::

## 四、禁止发布的内容

以下内容**一律禁止**发布或讨论，情节严重者直接移出，并按第六节在全部 AWMC 服务范围内处理：

1. **未经证实的内容** —— 小道消息、爆料、「据说」、未经核实的截图与传闻；
2. **转发抽奖、帮挂抽奖、集赞互帮** —— 任何形式的拉人、拉票、助力、砍价、拼团链接；
3. **舞萌 DX 的破解、修改、外挂相关内容** —— 也包括改机、私服、盗号、代练、账号买卖与共享；
4. **任何可能影响舞萌 DX 中国服务器运营的细节内容**；
5. **任何形式的广告与推广** —— 第三方产品、服务、社群、站点、直播间、接单与引流；
   可分享的范围仅限**主流社交媒体平台的内容**与 **AWMC / RankHub 相关服务**；
6. **其他同类服务与 Bot** —— 禁止在群内提及其他查分 Bot、状态站、群管工具等同类服务，
   包括**推荐、比较、评测、拉人、引流**等任何形式。本群只讨论 AWMC / RankHub
   自身的使用与问题；
7. **私聊拉人** —— 以私聊方式向群成员发广告、拉群、推销，同样按广告处理；
8. **他人的账号凭据** —— `SGWCMAID`、官方二维码链接、查分器 Token 等，禁止索取、转发与展示；
9. **跨群挂人与断章取义转发** —— 把群内聊天记录（含群主、管理员、群友发言）断章取义地
   截图搬运到其他群聊或平台；在其他群聊公开辱骂、嘲讽、围攻群友；
10. 违法、色情、赌博、暴力、政治敏感、涉未成年人不良内容，以及其他违反平台规定的内容。

::: info 关于第 6 条的边界
本条针对的是**其他同类服务与 Bot**，不是禁止提及任何外部名词。
AWMC Bot 自身功能的组成部分（例如水鱼 / 落雪上传、TapTap 云存档、机厅数据源等）
属于正常使用讨论，可以正常提问与解答。
::: 

::: danger 关于「敏感细节」
涉及舞萌 DX 服务器、接口与运营的任何**未公开细节**，请不要在群内讨论或传播。
这不是「话题禁忌」，而是为了保住大家正在用的服务：相关内容一旦扩散，受影响的会是所有人。
:::

## 五、消息秩序

- **禁止恶意刷屏**：重复发送相同内容、大量无意义表情包、刷图、刷语音、连续 @ 等。
- 引用回复请截取必要部分，不要整段长文反复引用。
- Bot 指令请在合适场合使用，避免用长指令（如整页帮助、批量查询）连续刷屏；
  **禁止滥用 Bot 接口**批量刷取数据或占用资源。
- 讨论与提问请分条发送，一条消息说清一件事。

## 六、违规处理

管理员会按**情节轻重**与**次数**处理，常见的处理阶梯如下：

| 情形 | 处理方式 |
| --- | --- |
| 轻微、初犯（跑题刷屏、轻度不文明） | 口头提醒、撤回消息 |
| 昵称不合规（`OPENID`、乱码、伪装 Bot 或他人） | 提醒改名；**经提醒仍未修改的，移出群聊** |
| 第三方机器人入群（OneBot / NapCat / SL 等自建 Bot、签到推送类 Bot） | **直接踢出（移出群聊）**，不另行警告 |
| 骚扰管理团队（反复 @ 催问、私聊无端打扰） | **禁言 1 日** |
| 一般违规（刷屏、转载未经证实内容、轻度广告） | 警告并记录 |
| 提及其他同类服务或 Bot（含推荐、比较、引流） | 提醒并撤回；重复或明确引流按下一档处理 |
| 重复违规或明确违规（广告、抽奖转发、凭据外传） | **禁言 10 分钟 ~ 24 小时** |
| 严重违规（辱骂攻击、破解外挂内容、影响服务器运营的细节、恶意滥用接口） | **移出群聊（踢出）** |
| 辱骂、谩骂机器人、管理层、项目制作人或负责人 | **永久封号** |
| 断章取义搬运群内发言到其他群聊 / 在别群公开辱骂群友 | **直接永久拉黑**，不作警告 |
| 极其严重或屡教不改（人肉搜索、诈骗、组织性违规、被踢后反复骚扰） | **移出并永久拉黑**，必要时同步平台举报 |

几点说明：

- 广告、外挂破解、人肉攻击、凭据外传等**明显违规不事先警告**，可直接禁言或移出；
- **昵称不合规**（`OPENID`、乱码、伪装 Bot 或官方、冒充他人）以**整改为先**：先提醒改名，
  拒不整改或改后复犯的移出群聊；以伪装身份实施诈骗、诱导等行为的，直接按严重违规处理；
- **第三方机器人入群**不设整改期：发现即踢，不看它说没说过话、也不看拉它进来的是谁；
  同一 Bot 被踢后反复拉回的，拉人者按**重复违规**升级处理；
- **断章取义挂人、跨群辱骂群友**属于**零容忍**项：一经发现即永久拉黑，
  同时适用于涉事的全部 AWMC 群聊；
- **无端骚扰**（反复 @ 群主 / 管理团队催问、私聊打扰、被提醒后仍不停）**默认禁言 1 日**，
  不因「只是一直问问题」而豁免：问问题请去论坛发帖；
- **提及其他同类服务与 Bot**（第四节第 6 条）：一般提及以**提醒并撤回**为主；
  以推荐、比较、拉人、引流为目的，或在被提醒后继续的，按**禁言 10 分钟 ~ 24 小时**处理；
  明显为其他服务拉人引流的，视同广告处理；
- 禁言时长、是否移出由管理员按实际情况判断，多次小违规会累计升级处理；
- 处理记录会被保留，短期内在多个群重复违规按同一人累计。

### 违规的跨服务影响

群内违规**不限于群聊层面的处理**。对于情节严重或屡次违规的用户，AWMC 团队有权在
**全部 AWMC 服务范围内**限制或封禁其账号，包括但不限于：

| 服务 | 可能的影响 |
| --- | --- |
| **AWMC BOT** | 限制或封禁查分、上传、群功能与账号相关指令 |
| **AWMC API** | 撤销密钥、限制调用额度或封禁接入 |
| **AWMC KOA** | 限制或封禁相关功能与权限 |
| **赛事与活动** | 取消参赛资格、成绩或已获得的奖励 |

跨服务处理的范围与期限由 AWMC 团队根据违规情节判定。具体的账号限制规则另见
[服务协议与隐私政策](/guide/bot/terms)。

## 七、责任与申诉

- 你在群内的所有发言须遵守**所在平台的服务条款与社区规范**。因违反平台规定导致的
  封号、限制等后果，本群不承担任何责任。
- 因使用 AWMC Bot 产生的数据与风险，按[服务协议与隐私政策](/guide/bot/terms)处理。
- 对处理结果有异议，请**私聊管理员**说明情况，不要在群内公开对线；管理员会复核，
  误判会撤销处理并致歉。**正常申诉不属骚扰**，只要说清事实、不刷屏催问即可。
- 本页提到的「禁止骚扰」指的是无端、反复、被提醒后仍继续的打扰，不包括正常求助与申诉。
- 永久拉黑类处理同样接受**一次**申诉：请私聊管理员并提供完整上下文，管理员核实后
  确属误判的会撤销；但**不因此改变「不事先警告」的原则**。
- 本页规则可能随时调整，**修改恕不另行通知**；请以本页当前内容为准，继续留在群内
  即视为接受最新版本。
