# 交流群群规

::: tip 一句话
AWMC x RankHub 交流群是围绕 **舞萌 DX** 与 **AWMC / RankHub** 服务的交流空间。
为了让大家聊得舒服、也让服务走得长远，请花两分钟看看下面的约定喵～
:::

本页适用于下列全部官方交流群，以及 AWMC Bot 所在的其他群聊。**进群即视为已阅读并同意本页内容。**

## 二、相互尊重

- 文明发言。**禁止**辱骂、人身攻击、威胁、歧视、地域黑、挂人、人肉搜索等行为。
- 观点不同很正常，请就事论事，不要针对个人；不要在群里追着人对线。
- 不拿他人的隐私、外貌、身份玩梗，也不开让人不适的玩笑。
- **禁止冒充**官方、管理员、Bot 或他人身份发布信息。

::: danger 禁止跨群挂人与断章取义转发（永久拉黑）
**禁止**把群内的聊天记录（群主、管理员、Bot 管理员、群友的发言）**断章取义**地截图、
转发或搬运到其他群聊、其他平台，用来挂人、带节奏、挑事或报复。

**禁止**在其他群聊、其他平台针对群友的发言进行**公开辱骂、嘲讽、挂人**或组织围攻。

违反本条**一经发现即永久拉黑**，不作警告，不接受「只是开个玩笑」「只是转给朋友看看」
一类的解释。群内讨论就留在群内解决；确有需要向管理团队反映，请**私聊**并附完整上下文，
而不是把截图片段散播出去。
:::

## 三、理性交流

- 鼓励积极解答他人的问题，但**没有人有义务必须回答**。
- 问题长时间无人回应时，请先检查表述是否清晰、是否提供了足够的背景信息
  （平台、版本、报错原文、复现步骤等）。信息越具体，越容易被解答。
- 求助前请先看[帮助文档](/guide/introduction)与[指令帮助](/guide/bot/advanced)，
  文档里已经写明的问题，请勿反复刷屏追问。
- 遇到 Bug、账号异常、数据错误或功能建议，请到[论坛](https://bbs.wmc.pub/forums/awmc-bot.17/)发帖，
  而不是在群里 @ 群主或管理团队。
- 请勿长时间刷与主题无关的话题。

::: warning 遇到问题请去论坛发帖，不要 @ 群主或管理团队
群主与管理团队**不是客服**。遇到 Bug、账号异常、数据错误、功能建议等问题，请先查
[帮助文档](/guide/introduction)与[指令帮助](/guide/bot/advanced)；仍然解决不了的，
请到**论坛**发帖提问：

👉 **[AWMC Bot 版块 · bbs.wmc.pub/forums/awmc-bot.17](https://bbs.wmc.pub/forums/awmc-bot.17/)**

发帖时请写清问题描述、复现步骤，并附上 Bot 返回的 `Ref_ID`，方便定位。
在群里反复 @ 群主、管理或 Bot 管理员催问，或以私聊方式无端骚扰管理团队与群成员，
都属于**骚扰行为**：轻则提醒，重则**禁言 1 日**，屡犯按第六节升级处理。
:::

## 四、禁止发布的内容

以下内容**一律禁止**发布或讨论，情节严重者直接移出：

1. **未经证实的内容** —— 小道消息、爆料、「据说」、未经核实的截图与传闻；
2. **转发抽奖、帮挂抽奖、集赞互帮** —— 任何形式的拉人、拉票、助力、砍价、拼团链接；
3. **舞萌 DX 的破解、修改、外挂相关内容** —— 也包括改机、私服、盗号、代练、账号买卖与共享；
4. **任何可能影响舞萌 DX 中国服务器运营的细节内容**；
5. **任何形式的广告与推广** —— 第三方产品、服务、社群、站点、直播间、接单与引流；
   可分享的范围仅限**主流社交媒体平台的内容**与 **AWMC / RankHub 相关服务**；
6. **私聊拉人** —— 以私聊方式向群成员发广告、拉群、推销，同样按广告处理；
7. **他人的账号凭据** —— `SGWCMAID`、官方二维码链接、查分器 Token 等，禁止索取、转发与展示；
8. **跨群挂人与断章取义转发** —— 把群内聊天记录（含群主、管理员、群友发言）断章取义地
   截图搬运到其他群聊或平台；在其他群聊公开辱骂、嘲讽、围攻群友；
9. 违法、色情、赌博、暴力、政治敏感、涉未成年人不良内容，以及其他违反平台规定的内容。

::: danger 关于「敏感细节」
涉及舞萌 DX 服务器、接口与运营的任何**未公开细节**，请不要在群内讨论或传播。
这不是「话题禁忌」，而是为了保住大家正在用的服务：相关内容一旦扩散，受影响的会是所有人。
:::

## 五、消息秩序

- **禁止恶意刷屏**：重复发送相同内容、大量无意义表情包、刷图、刷语音、连续 @ 等。
- 引用回复请截取必要部分，不要整段长文反复引用。
- Bot 指令请在合适场合使用，避免用长指令（如整页帮助、批量查询）连续刷屏；
  **禁止滥用 Bot 接口**批量刷取数据或占用资源。
- 讨论与提问请分条发送，一条消息说清一件事。

## 六、违规处理

管理员会按**情节轻重**与**次数**处理，常见的处理阶梯如下：

| 情形 | 处理方式 |
| --- | --- |
| 轻微、初犯（跑题刷屏、轻度不文明） | 口头提醒、撤回消息 |
| 骚扰管理团队（反复 @ 催问、私聊无端打扰） | **禁言 1 日** |
| 一般违规（刷屏、转载未经证实内容、轻度广告） | 警告并记录 |
| 重复违规或明确违规（广告、抽奖转发、凭据外传） | **禁言 10 分钟 ~ 24 小时** |
| 严重违规（辱骂攻击、破解外挂内容、影响服务器运营的细节、恶意滥用接口） | **移出群聊（踢出）** |
| 断章取义搬运群内发言到其他群聊 / 在别群公开辱骂群友 | **直接永久拉黑**，不作警告 |
| 极其严重或屡教不改（人肉搜索、诈骗、组织性违规、被踢后反复骚扰） | **移出并永久拉黑**，必要时同步平台举报 |

几点说明：

- 广告、外挂破解、人肉攻击、凭据外传等**明显违规不事先警告**，可直接禁言或移出；
- **断章取义挂人、跨群辱骂群友**属于**零容忍**项：一经发现即永久拉黑，
  同时适用于涉事的全部 AWMC 群聊；
- **无端骚扰**（反复 @ 群主 / 管理团队催问、私聊打扰、被提醒后仍不停）**默认禁言 1 日**，
  不因「只是一直问问题」而豁免：问问题请去论坛发帖；
- 禁言时长、是否移出由管理员按实际情况判断，多次小违规会累计升级处理；
- 处理记录会被保留，短期内在多个群重复违规按同一人累计。

## 七、责任与申诉

- 你在群内的所有发言须遵守**所在平台的服务条款与社区规范**。因违反平台规定导致的
  封号、限制等后果，本群不承担任何责任。
- 因使用 AWMC Bot 产生的数据与风险，按[服务协议与隐私政策](/guide/bot/terms)处理。
- 对处理结果有异议，请**私聊管理员**说明情况，不要在群内公开对线；管理员会复核，
  误判会撤销处理并致歉。**正常申诉不属骚扰**，只要说清事实、不刷屏催问即可。
- 本页提到的「禁止骚扰」指的是无端、反复、被提醒后仍继续的打扰，不包括正常求助与申诉。
- 永久拉黑类处理同样接受**一次**申诉：请私聊管理员并提供完整上下文，管理员核实后
  确属误判的会撤销；但**不因此改变「不事先警告」的原则**。
