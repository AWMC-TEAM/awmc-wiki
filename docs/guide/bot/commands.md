# AWMC QueryBot 指令调用说明

本页说明账号、上传、BREAK 与管理指令的调用方式。查歌、B50、猜歌、数据报告等完整
查询指令请见 [指令帮助](/guide/bot/advanced)。

::: warning 版本说明
账号功能已经合并到 QueryBot。旧 Koishi maiBot 的优先卡密、解绑卡、账号锁定、保护模式、
账号读写功能已迁移到 AWMC Gateway API；批量 `upsert-all` 不对用户开放。

账号**写操作**（成绩、道具、资料修改）已升级到 **AWMC API v2-3 会话制**：Bot 提交后由服务端
后台执行，并自动完成服务端会话确认与轮询；用户仍须先确认操作摘要与风险。相关指令与价格见
[第八节 账号编辑与批量操作](#八、账号编辑与批量操作-v2-3)。
:::

## 一、通用规则

- 指令前缀由平台配置决定；本文默认不写 `/`。
- 账号和上传流程会引用触发消息；敏感凭据直发因原消息会先撤回，群聊结果改用 `@用户` 标识。
- 交互流程通常支持 `取消`、`cancel`、`q` 或 `退出`。
- 二维码、官方二维码链接和 Token 都是敏感凭据，Bot 会优先尝试撤回。
- 外部调用会生成 `Ref_ID`；发生异常时请把它提供给管理员，不要发送 Token 或 UID。

## AI 生图

| 指令 | 说明 |
|---|---|
| `画图 <描述>` | 文字生图，默认消耗 358 BREAK；失败会退回预扣 BREAK |
| `画图 <描述> -p` / `--reference` | 图生图：发送命令后，再按提示发送参考图 |
| `画图 <描述> -q auto` | 指定质量参数，当前仅支持 `auto` |

官方 QQ 群聊可以直接 `@机器人 画图 <描述>`；也可以在同一条消息中附图。
提示词最长 4000 字符，参考图默认不超过 8 MB，支持 PNG、JPEG、WebP。生图前会进行内容审核，违法违规、敏感政治、未成年人色情等请求不会扣 BREAK；参考图仍会执行安全检查。

服务端升级到 v2-3 后不再提供门状态（`get-kaleidx-scope`）与活动事件（`get-game-event`）读取接口，
此时 `mai门状态` / `maievent` 会提示该查询已移除；账号道具可改用 `mai道具` 查询。
**门状态的修改**走 `mai改门`（见 [第八节](#八、账号编辑与批量操作-v2-3)），写入接口支持门 1～6。
:::

二维码输入支持：

```text
SGWCMAID...
https://wq.wahlap.net/qrcode/img/MAID....png
https://wq.wahlap.net/qrcode/req/MAID....html
```

所有使用账号二维码凭据的 API 指令都会检查缓存有效期（**二维码生成时间 + 10 分钟**）。
缓存失效时不会继续使用旧凭据，请直接发送最新 SGWCMAID、官方二维码链接或二维码图片，
验证刷新后重新执行原指令。

凭据无效、过期、返回 500/全空或身份不一致时，Bot 最多重新询问 3 次。
管理员可用 `BREAK配置` 调整与二维码相关的热配置，常用的有：

| 键 | 说明 |
|---|---|
| `one_time_qrcode` | `1` = **一次性二维码**：一个二维码只服务一次用到二维码的操作，之后的操作用户需重新发码（默认 `0`，即 10 分钟内复用） |
| `qrcode_freeze_enabled` / `qrcode_freeze_seconds` | 连续 3 次验码失败后按用户冻结的开关与秒数 |
| `checkin_cooldown_mode` | 签到冷却口径：默认 `24h`（距上次成功签到满 24 小时）；填 `daily` 回退到「每日 00:00 重置」 |

### 无二维码快速更新与自动更新 {#quick-update}

::: warning 版本与前提
以下按当前 QueryBot 源码说明，需部署包含该功能的 Bot 及支持 rival 读取的上游服务；不代表所有实例已经上线。价格、时长和容量均可由管理员调整，以 Bot 实际提示为准。
先用 `mai绑定` 绑定舞萌账号；如需同步水鱼或落雪，请先完成 `dfbind` / `lxbind` OAuth 绑定。仅绑定上传 Token 不会用于此快速更新路径。
:::

| 指令 | 说明 |
|---|---|
| `mai对手同步` / `rival同步` | 无需重新扫码，读取已绑定账号的成绩并同步 AWMCNET；有 OAuth 时也同步对应查分器 |
| `导` / `u` / `更` / `更新` | 同上，需整条消息只含该快捷词；群游戏进行时快捷词会被忽略，可改用完整命令 |
| `mai自动更新 [小时]` / `自动更新 [小时]` | 开启限时后台更新；默认 3 小时，支持如 `6`、`6小时`、`6h` |
| `查自动更新` / `mai查自动更新` | 查看剩余时长、下次同步时间、次数与最近结果 |
| `自动更新关闭` / `mai自动更新关闭` | 提前关闭自动更新，剩余时长不退款 |
| `查任务` / `查进度` | 查看后台上传任务与结果；已加入队列不等于外部查分器已完成上传 |

- 合并已有快照：保留旧记录，仅在达成率更高时覆盖。成功同步后才进入默认 **300 秒**用户冷却；拉取失败、配额拒绝或成绩为空不进入冷却，可立即重试。
- **不刷新 FC/FS 标记和 PC 数**。需要完整更新时仍应发送最新二维码；不要将此路径当作全量扫码上传。
- 自动更新走相同的快速更新路径，默认每 **15 分钟**一轮；频率还受快速更新冷却影响。
- 默认可开 **1～12 小时**、全服同时最多 **10 人**，每人只能有一个时段。
- 默认 **30 BREAK / 小时**（3 小时共 90 BREAK），发送 `确认` 后预付整个时段费用；回复其他内容取消。它不是每次同步成功才扣费，提前关闭不退款。

管理员可用 `BREAK配置 <键> <值>` 调整：

| 键 | 默认值 / 用途 |
|---|---|
| `rival_sync_cooldown_seconds` | `300`，快速更新冷却秒数，`0` 关闭冷却 |
| `auto_update_enabled` | `1`，自动更新总开关 |
| `auto_update_fee_per_hour` | `30`，每小时 BREAK |
| `auto_update_default_hours` / `auto_update_max_hours` | `3` / `12`，默认 / 最长时段 |
| `auto_update_interval_minutes` | `15`，同步间隔分钟数（实际还受冷却约束） |
| `auto_update_max_sessions` | `10`，同时开启人数上限 |

::: tip 开发者：AWMCNET 分块同步

| 指令 | 说明 |
|---|---|
| `mai改成绩` / `改成绩` / `改分` | 交互选择歌曲、难度和成绩；成功扣 258 BREAK / 谱面 |
| `mai改成绩` / `改分 <歌曲> <难度> <达成率> <DX分> [FC] [FS] [简单/专业]` | 一步编辑成绩 |
| `mai删成绩` / `删成绩` / `删分` | 交互选择歌曲和难度；成功扣 50 BREAK / 谱面 |
| `mai删成绩` / `删分 <歌曲> <难度>` | 一步删除成绩 |
| `mai改道具` / `改道具` | 高风险交互式道具修改；成功扣 100 BREAK / 次 |
| `mai改道具` / `改道具 <itemKind> <itemId> <add/del>` | 预填参数后仍需确认风险 |

### 批量成绩（一次最多 20 条，按谱面计费）

`mai改成绩` 支持用换行或分号（`;` / `；`）分隔，一次提交**最多 20 条**成绩：

```text
mai改成绩
歌曲A 紫 100.5% 5 AP FDX
歌曲B 黄 99.8% 4 FC FS
```

`mai删成绩` 同样支持批量（每条写成 `<歌曲> <难度>`）。

- 同一首歌的同一个难度不能重复出现。
- 一次批量必须**统一模式**：DX 分要么全部填星级（简单模式），要么全部填实际 DX 分（专业模式）。
- **按谱面条数计费**：默认修改每条 258 BREAK、删除每条 50 BREAK；例如修改 2 条共 516 BREAK。
- 写入完成后会显示服务端验证结果与上传/跳过条数；账号已满足条件时会提示“无需上传”。

交互模式同样可以累计多条：录完一条后发送 `继续添加`（或 `继续编辑`）返回选歌，
`查看列表` 查看待提交项，`删曲目 N` 移除第 N 项；`完成并提交`（也可 `完成` / `提交`）
查看最终清单与总价，再发送 `确认修改`（删除为 `确认删除`）才执行。`取消` 放弃整批。
批量删成绩不保证可用，且 Bot 无法自动恢复已删除成绩，请先核对清单与风险。

### 成绩格式

成绩命令支持歌曲 ID、完整曲名和别名；交互选择难度时可发送数字：`0 BASIC`、`1 ADVANCED`、
`2 EXPERT`、`3 MASTER`、`4 Re:MASTER`；没有 Re:MASTER 谱面的歌曲只能选择 `0-3`。
难度也支持 `BASIC/ADV/EXP/MAS/Re:MAS`、
绿/黄/红/紫/白，以及宴会场的“宴”。达成率可写 `100.5%`，也可写 `0.995`
（自动解析为 `99.5%`）。

- **简单模式（默认）**：DX 分填写星级 `0～5`。
- **专业模式**：DX 分填写实际 DX 分；填写大于 5 的数值会自动选择专业模式，并校验谱面满分。
- 可显式追加 `简单` 或 `专业`；支持 `FC/FCP/AP/APP` 和 `FS/FSP/FDX/FDXP`。
- API、解析、超时或取消失败时不扣 BREAK；写接口不会自动重试。

::: tip 道具类型
`mai改道具` 的 `itemKind` 支持：1 姓名框、2 称号、3 头像、4 收藏品、5 乐曲解锁、
6 MASTER 谱面解锁、7 Re:MASTER 谱面解锁、10 搭档、11 边框。
角色请使用 `mai改角色`；票券不支持道具写入（须上机购买或使用发票）。
:::

::: danger 道具修改风险
`mai改道具` **未经实际账号测试**，可能造成数据异常或不可逆后果，尤其是
`itemKind=4/8`。Bot 会展示操作摘要，并要求发送“我已知晓风险”后才执行；
继续操作即表示风险由用户自行承担。批量 `upsert-all` 不提供用户命令。
:::

## 八、账号编辑与批量操作（v2-3）

账号写操作已升级到 **AWMC API v2-3 会话制**：Bot 提交请求后由服务端后台执行
（登录 → 分轮上传 → 服务端验证 → 登出），Bot 自动完成“创建 + 立即确认”并轮询结果，
**服务端会话无需额外手动确认，但用户仍须确认操作摘要、总价与风险后才提交**。单次执行通常 1～2 分钟。

`mai改资料`（别名 `资料修改` / `改资料` / `资料命令`）是**集合入口**，会列出全部写操作指令、
当前价格，并提供一键进入各指令的按钮。

| 指令 | 说明 | 价格（成功才扣） |
|---|---|---|
| `mai批量编辑` / `批量编辑` / `批量改` | 一次对话收集多项修改（可跨类型），串行执行 | 各项价格累加 |
| `mai全解锁 [music/master/remaster] [版本ID]` | 一键解锁乐曲 / MASTER / Re:MASTER | 200 BREAK / 次 |
| `mai改门 <门 1～6 或名称> <found/key/both/off>` | 修改 Kaleidx Gate 状态 | 50 BREAK / 次 |
| `mai改rating <0~99999>` | 修改显示 Rating（不改历史最高） | 50 BREAK / 次 |
| `mai改里程 <0~99999>` | 修改舞萌里程 | 50 BREAK / 次 |
| `mai改地图库存 <0~999>` | 修改地图库存 | 50 BREAK / 次 |
| `mai改游玩次数 <累计> [当前版本]` | 修改游玩次数 | 50 BREAK / 次 |
| `mai改段位 <段位或ID>` | 修改段位（0～23） | 50 BREAK / 次 |
| `mai改阶级 <阶级或ID>` | 修改阶级（0～25） | 50 BREAK / 次 |
| `mai改搭档 <角色或ID>` | 用该角色填满五个搭档栏位 | 50 BREAK / 次 |
| `mai改角色 <角色或ID> <等级> [觉醒]` | 修改角色等级 / 觉醒 | 50 BREAK / 次 |
| `mai改亲密度 <搭档或ID> <等级>` | 修改搭档亲密度 | 50 BREAK / 次 |
| `mai完成地图 <地图或ID…>` | 临时停用：上游保存验证失败（5006） | 不执行 |
| `mai推进地图 <地图或ID…>` | 临时停用：上游保存验证失败（5006） | 不执行 |
| `mai改登录奖励 <奖励或ID…>` | 临时停用：上游保存验证失败（5006） | 不执行 |
| `mai重置版本` | 重置到当前服务使用的游戏版本 | 50 BREAK / 次 |
| `查进度 [<session_id>]` | 查询自己的任务看板或指定上传会话（别名 `查任务` / `mai查任务` / `查上传任务` / `查会话`） | 免费 |

### 批量编辑：一次改多项

v2-3 的每个上传接口只接受自己那一类数据（成绩 / 道具 / 各项资料），**跨类型无法合并成一个请求**，
因此批量编辑采用「一次对话收集 → 串行执行多个上传会话」：

```text
mai批量编辑
改rating 16000
改道具 5 11479 add
改成绩 歌曲A 紫 100.5% 5 AP FDX
完成
确认修改
```

- 逐条发送要修改的内容，**最多 3 项**（每项一次上传会话，约 1～2 分钟）。
- 可分多条消息录入，也可一次发送多行；`继续添加` 继续收集，`查看列表` 查清单，`删曲目 N` 移除第 N 项。
- 发送 `完成并提交`（或 `完成` / `提交`）查看清单与总价，发送 `确认修改` 开始执行（`取消` 退出）。
- **按各项服务价格累加，仅对确认成功的项目扣费**。例如改 Rating 50 + 改道具 100 + 改 1 条成绩 258 = 408 BREAK。
- 明确失败的项目会记录原因并继续；结果不确定或结算异常时停止，先用 `查任务` 核实，不要重复提交。二维码过期续跑只继续未完成项。
- 可写入的内容：`改门` / `改rating` / `改里程` / `改地图库存` / `改游玩次数` / `改段位` /
  `改阶级` / `改搭档` / `改角色` / `改亲密度` / `重置版本` / `改道具` / `改成绩` / `删成绩` / `全解锁`。
- `改地图` / `推进地图` / `改登录奖励` 当前临时停用，批量入口与二维码续跑也不能绕过。

### 名称输入（不知道 ID 也能改）

带“或名称”的参数都可以直接输入名字，Bot 会自动查询上游资源并转换为 ID：

```text
mai改门 紫色之门 found     # 门名 → ID 3
mai改角色 星 <等级>        # 角色名 → 角色 ID
```

- 名称匹配由上游完成（不区分大小写，支持关键词）。
- 匹配到多个同名资源时会列出候选，改用更精确的名称或直接填 ID 即可。
- 段位 / 阶级的名称由上游提供（段位名带版本前缀，如 `1.17_初段`），因此更推荐直接填写数值
  （段位 `0~23`、阶级 `0~25`）。

### 一键全解锁

```text
mai全解锁            # 全部乐曲
mai全解锁 master     # 全部 MASTER 谱面解锁
mai全解锁 remaster 25 # 指定版本范围的 Re:MASTER
```

候选清单由上游生成，账号**已拥有的会自动跳过**（全部跳过时不会上传）。确认后扣 200 BREAK，
不随曲目数量加价。

### 计费与失败处理

- 上述价格均可在数据库配置中调整（管理员 `BREAK配置`）。
- 上游明确失败（参数不被接受、账号状态异常等）不扣 BREAK；会话执行中途失败会回报具体原因。
- 超时或网络中断时 Bot **不会自动重投**（避免重复写入），可用 `查进度` 查询实际结果。
- 写操作支持**二维码过期续跑**：提示二维码失效后发送最新二维码，Bot 会继续原操作。
- 多数修改会产生一局游玩记录并影响 Rating 显示，上机游玩一局后会自动重算。

不带参数的 `查任务` / `查进度` 还会显示二维码、后台同步与发票等任务；管理员可看全服近期任务，普通用户仅看自己的任务。指定 `session_id` 时也按权限查询；“需核对”不等于一定未写入。
