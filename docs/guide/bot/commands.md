# AWMC QueryBot 指令调用说明

本页说明账号、上传、BREAK 与管理指令的调用方式。查歌、B50、猜歌、数据报告等完整
查询指令请见 [指令帮助](/guide/bot/advanced)。

::: warning 版本说明
账号功能已经合并到 QueryBot。旧 Koishi maiBot 的优先卡密、解绑卡、账号锁定、保护模式、
账号读写功能已迁移到 AWMC Gateway API v2；批量 `upsert-all` 不对用户开放。
:::

## 一、通用规则

- 指令前缀由平台配置决定；本文默认不写 `/`。
- 账号和上传流程会引用触发消息；敏感凭据直发因原消息会先撤回，群聊结果改用 `@用户` 标识。
- 交互流程通常支持 `取消`、`cancel`、`q` 或 `退出`。
- 二维码、官方二维码链接和 Token 都是敏感凭据，Bot 会优先尝试撤回。
- 外部调用会生成 `Ref_ID`；发生异常时请把它提供给管理员，不要发送 Token 或 UID。

## AI 生图

| 指令 | 说明 |
|---|---|
| `画图 <描述>` | 文字生图，默认消耗 358 BREAK；失败会退回预扣 BREAK |
| `画图 <描述> -p` / `--reference` | 图生图：发送命令后，再按提示发送参考图 |
| `画图 <描述> -q auto` | 指定质量参数，当前仅支持 `auto` |

官方 QQ 群聊可以直接 `@机器人 画图 <描述>`；也可以在同一条消息中附图。
提示词最长 4000 字符，参考图默认不超过 8 MB，支持 PNG、JPEG、WebP。生图前会进行内容审核，违法违规、敏感政治、未成年人色情等请求不会扣 BREAK；参考图仍会执行安全检查。

## 二、协议与账号

| 指令 | 说明 |
|---|---|
| `用户协议` | 查看当前协议链接和确认方法 |
| `同意用户协议 <完整确认词>` | 确认协议；也可直接发送完整确认词 |
| `撤回用户协议` | 撤回当前版本的同意 |
| `不同意共享我的数据` | 关闭成绩/Rating/趋势等脱敏公开与训练使用（默认开启，详见[协议](/guide/bot/terms#2-公开数据与训练使用默认开启)） |
| `mai账号` | 查看账号功能帮助 |
| `mai绑定` / `maibind` | 交互式绑定或认领舞萌账号 |
| `mai绑定 <二维码或链接>` | 一次提交并绑定 |
| `mai解绑` | 解绑舞萌账号，上传 Token 保留 |
| `mai状态` / `mymai` | 查看完整账号状态；缓存失效时重新询问二维码 |
| `舞萌状态` / `mais` | 服务器失败率折线图 + 实时状态（见 [指令帮助](/guide/bot/advanced#11-帮助与信息)） |
| `maiping` | 检查 AWMC API 连接 |
| `mai地图` | 查看游玩地区（服务支持时） |
| `mai预览` / `预览` | 查询账号预览；成功后扣 5 BREAK |
| `mai道具` / `道具` | 查询全部道具；成功后扣 5 BREAK |
| `mai门状态` / `查门` / `门状态` | 查询 Kaleidx Gate 的发现、钥匙与通关状态；成功扣 5 BREAK |
| `mai查询opt <版本号>` | 查询 Mai2 选项文件 |

门状态会同时显示 Gate 名称：1 蓝色之门、2 白色之门、3 紫色之门、4 黑色之门、
5 黄色之门、6 红色之门、7 棱镜塔、8 表门、9 希望之门、10 里门。

二维码输入支持：

```text
SGWCMAID...
https://wq.wahlap.net/qrcode/img/MAID....png
https://wq.wahlap.net/qrcode/req/MAID....html
```

所有使用账号二维码凭据的 API 指令都会检查缓存有效期。缓存失效时不会继续使用旧凭据，
请直接发送最新 SGWCMAID、官方二维码链接或二维码图片，验证刷新后重新执行原指令。

凭据无效、过期、返回 500/全空或身份不一致时，Bot 最多重新询问 3 次。

## 三、查分器绑定与上传

| 指令 | 说明 |
|---|---|
| `mai绑定水鱼 <Token>` / `maibindfish <Token>` | 绑定水鱼 Token |
| `mai解绑水鱼` | 解绑水鱼 Token |
| `lxbind` | 绑定落雪 OAuth（推荐） |
| `lxunbind` | 解绑落雪 OAuth |
| `mai绑定落雪 <导入Token>` / `maibindlx <导入Token>` | 绑定落雪兼容 Token |
| `mai解绑落雪` | 解绑落雪兼容 Token |
| `maiu [二维码或链接]` | 上传水鱼 |
| `maiul [二维码或链接]` | 上传落雪 |
| `maiua [二维码或链接]` | 同时上传水鱼和落雪 |

三种上传共享每日首次成功免费额度。默认后续价格为水鱼 2、落雪 2、同时上传 3 BREAK；
失败、超时或取消均不扣费。

## 四、直接二维码与 PC

直接发送 `SGWCMAID...` 或受支持的官方链接，会自动完成 PC 同步，再按照绑定状态上传
水鱼、落雪或两边。未绑定查分器时只同步 PC。

| 指令 | 说明 |
|---|---|
| `更新pc数` | 使用缓存或最新二维码同步 PC |
| `我的pc数` | 查看个人 PC 统计 |
| `pc数 <歌曲>` | 查看指定谱面 PC |
| `pc50` | B50 按 PC 排序 |
| `pca50` | Rating B50 内按 PC 排序 |
| `游玩排行50` | 全库游玩最多的 50 个谱面 |
| `pc排行` | 所有已同步用户的 PC 总量排行 |

::: tip 开发者：AWMCNET 分块同步
QueryBot 或其他服务端将大量成绩同步到 AWMCNET 时，可以把全量快照拆成多个请求，
每块设置 `full_snapshot: true` 并复用同一个 `snapshot_id`。中间块不设置
`snapshot_final`，最后一块设置 `snapshot_final: true`；超时重试时继续使用同一个
`snapshot_id`。完整字段和示例见 [AWMCNET Bot API](/dev/awmcnet-api)。
:::

## 五、段位认定

当前段位表默认使用国服现行版本 **PRiSM PLUS**。查询结果会生成图片，包含段位 LIFE 规则、4 首课题曲、乐曲难度/定数、个人最高达成率，以及服务器近期成绩聚合出的匿名样本统计。

| 指令 | 说明 |
|---|---|
| `段位表` | 查看可查询段位列表与示例 |
| `段位表 <段位>` | 查询指定段位，如 `段位表 真二段` |
| `<段位>段位表` | 同上，如 `真二段段位表` |
| `段位表 <段位> @用户` | 查询被 @ 用户的个人成绩展示 |

图片中的段位资源会优先使用玩家当前名牌与官方段位 Plate；匿名样本来自服务器近期已同步且未关闭数据共享的成绩，低样本或冷启动时回退到内置样本。页脚会标明数据来源与「仅供练习参考，机台结果为准」。

## 七、成绩与道具写入

| 指令 | 说明 |
|---|---|
| `mai改成绩` / `改成绩` / `改分` | 交互选择歌曲、难度和成绩；成功扣 75 BREAK / 条 |
| `mai改成绩` / `改分 <歌曲> <难度> <达成率> <DX分> [FC] [FS] [简单/专业]` | 一步编辑单条成绩 |
| `mai删成绩` / `删成绩` / `删分` | 交互选择歌曲和难度；成功扣 50 BREAK / 条 |
| `mai删成绩` / `删分 <歌曲> <难度>` | 一步删除单条成绩 |
| `mai改道具` / `改道具` | 高风险交互式道具修改；成功扣 100 BREAK / 次 |
| `mai改道具` / `改道具 <itemKind> <itemId> <add/del>` | 预填参数后仍需确认风险 |

成绩命令支持歌曲 ID、完整曲名和别名；交互选择难度时可发送数字：`0 BASIC`、`1 ADVANCED`、
`2 EXPERT`、`3 MASTER`、`4 Re:MASTER`；没有 Re:MASTER 谱面的歌曲只能选择 `0-3`。
难度也支持 `BASIC/ADV/EXP/MAS/Re:MAS`、
绿/黄/红/紫/白，以及宴会场的“宴”。达成率可写 `100.5%`，也可写 `0.995`
（自动解析为 `99.5%`）。

- **简单模式（默认）**：DX 分填写星级 `0～5`，请求使用 `fuzzy=true`。
- **专业模式**：DX 分填写实际 DX 分；填写大于 5 的数值会自动选择专业模式，并校验谱面满分。
- 可显式追加 `简单` 或 `专业`；支持 `FC/FCP/AP/APP` 和 `FS/FSP/FDX/FDXP`。
- API、解析、超时或取消失败时不扣 BREAK；写接口不会自动重试。

::: danger 道具修改风险
`mai改道具` **未经实际账号测试**，可能造成数据异常或不可逆后果，尤其是
`itemKind=4/8`。Bot 会展示操作摘要，并要求发送“我已知晓风险”后才执行；
继续操作即表示风险由用户自行承担。批量 `upsert-all` 不提供用户命令。
:::

## 八、管理员指令

以下指令仅限 Bot 超级管理员或插件管理员：

| 指令 | 说明 |
|---|---|
| `查询REF <Ref_ID>` | 查看脱敏后的完整处理链路 |
| `封禁用户 <用户> [原因]` | 封禁用户 |
| `解封用户 <用户>` | 解除封禁 |
| `封禁列表` | 查看生效中的封禁 |
| `管理面板` / `WebUI` | 查看 WebUI 地址与配置状态 |
| `查看AWMC <用户>` | 查看用户 BREAK 资料 |
| `设置BREAK <用户> <数量>` | 直接设置余额 |
| `增减BREAK <用户> <数量>` | 增减余额 |
| `BREAK配置 [键 值]` | 查看或修改 BREAK 默认参数 |
| `迁移Koishi 检查 <数据库>` | 只读预检 Koishi 账号迁移 |
| `迁移Koishi 确认 <数据库>` | 确认迁移账号、Token 和协议记录 |
| `发票统计` / `ticket统计` / `returnCode统计` | 全局发票成功/失败与 `returnCode=0` 统计；可加天数，如 `发票统计 7` |
| `存储状态` | 查看 SQLite/YAML/MySQL 存储状态 |
| `存储迁移 检查 <源> <目标>` | 预检数据迁移 |
| `存储迁移 确认 <源> <目标>` | 确认迁移 |
| `存储同步` | 立即同步当前配置的远端存储后端 |

::: tip 统一存储（MySQL / YAML）
工作集未变更时可跳过打包；MySQL 未改文件可复用；启动时同步在后台执行，不阻塞 Bot 接消息。详见管理员 `存储状态` / `存储同步`。
:::

WebUI 和管理接口不会返回二维码、Token 或完整街机 UID；管理员修改也会记录 `Ref_ID`。

## 九、交互示例

### 绑定并上传两边

```text
用户协议
mai绑定
mai绑定水鱼 <Token>
lxbind
maiua
```

### 二维码失效

```text
Bot：二维码缓存已失效，请发送最新二维码（最多 3 次）
用户：SGWCMAID...
Bot：验证成功并继续原操作
```

### 查询问题

```text
用户：mymai
Bot：引用该消息，返回账号状态与 Ref_ID
```
