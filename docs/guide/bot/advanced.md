::: tip 提示
善用搜索快捷键 <kbd>/</kbd>（电脑端）或顶部搜索按钮（手机端）进行查询。
:::
::: tip 论坛账号绑定（qbind）

账号绑定、B50 上传、票券、PC 同步、成绩查询与群互动现已合并到同一个 QueryBot。
指令前缀由平台配置决定；下文以不带前缀为例。

## 一、账号、上传与 BREAK

开始前请先发送 `用户协议`，打开网页阅读并完整复制确认词。二维码相关指令支持
`SGWCMAID...`、Wahlap `img/MAID...png` 与 `req/MAID...html` 官方链接。

### 1.1 帮助与信息

| 命令 | 说明 |
|------|------|
| `mai账号` | 查看账号功能帮助 |

::: tip 我的猜歌数据
- 九玩法：猜歌 / 猜曲绘 / 猜曲子 / 猜铺面 / 开字母 / 猜 Rating / 找内鬼 / 二选一 / 你想我猜

- `@某人` 可看对方本群数据，例如 `我的猜歌 @张三`；无 at 仍查自己
- 群内发送 `我的AWMC` 会自动附带本群猜歌数据图（失败不影响账号状态主流程）
:::

::: tip 舞萌开字母
需先由群管发送 `开启mai猜歌`；与猜歌 / 曲绘 / 曲子 / 铺面**同群互斥**。

- 对局中直接发单个字母（如 `m`）开字符，或发曲名/别名猜中；也可 `开字母 m`、`开歌 xxx`
- 字母补齐完整标题时记入补齐者贡献（✅ 字母补齐）
- **局内不计分、不发 BREAK**；全部解开后按**用时星级 + 个人贡献**统一结算
- 用时精确到毫秒，展示为 `xx.xxx秒`
- **星级（自适应）**：默认 ≤30 / 45 / 60 / 90 / 180 秒对应 5～1 星；群内最近通关变快后，按历史用时 P35 收紧五星上限（最低 15 秒、最高仍 30 秒），其它星按 1 : 1.5 : 2 : 3 : 6 相对五星缩放；更慢为 0 星最低奖池。结算文案会显示本局生效阈值
- **贡献权重**：有效开字母 ×1、补齐曲 ×3、开歌 ×4；无贡献不得分；奖池按权重分配
- **限时×3**：活动一周内结算分数与 BREAK 三倍，文案/榜图标注「限时×3」；过期自动恢复 1 倍
- 通关结算顺序：① 猜中/补齐文案 + 用时星级 + 奖池 ② 本局榜单·贡献分成图 ③ 全开看板图；亦可随时查 `开字母排行` / `开字母贡献榜` / `开字母时间榜`
- **人多文字模式**：贡献人数或短时突发达阈值时，局中看板降级为纯文字；通关结算仍强制出图
- 非高峰另有 **2.5 秒/人**冷却（与下方猜歌全局限频独立）；进入文字模式后跳过
- `不玩了` / `结束开字母`：结束并揭晓剩余，**不发**速度奖与贡献奖（不用通关奖池文案）
:::

::: warning 答题限流
同一用户全局 **2.5 秒**只能提交一次答案（猜歌 / 曲绘 / 曲子 / 铺面 / 猜 Rating / 找内鬼）。超限时提示：

`嘿嘿，你的答案被我吃掉啦！(x.x秒后才能发送新的答案）`
:::

::: tip 猜 Rating
需先由群管发送 `开启mai猜歌`；与其它猜歌玩法及开字母 **同群互斥**。

- 随机选一位群友 → 按难度隐藏其 B50 身份和成绩 → 60 秒内发数字猜 Rating → 可修改答案 → 最接近者获胜
- `猜Rating` 随机难度；`猜Rating1`～`猜Rating5` 指定难度；可在后面附加 10～300 秒作答时间，例如 `猜Rating3 90`
- 被抽中的题主不能提交有效答案，也不会进入排名或获得奖励
- 结算：倒计时结束 → 揭晓真实 Rating + 昵称 → 发放积分 / BREAK → 展示完整 B50 图

**分级条件与前三名奖励**：

| 难度 | 展示/隐藏 | 🥇 | 🥈 | 🥉 |
|------|-----------|----|----|----|
| 1 | 20 张；保留成绩等级、FC/FS | 15分 + 2 BREAK | 5分 + 1 BREAK | 3分 |
| 2 | 16 张；隐藏 FC/FS | 18分 + 2 BREAK | 6分 + 1 BREAK | 4分 |
| 3 | 12 张；再隐藏成绩等级 | 21分 + 2 BREAK | 7分 + 1 BREAK | 5分 |
| 4 | 8 张；仅保留最少识别信息 | 24分 + 2 BREAK | 8分 + 1 BREAK | 6分 |
| 5 | 4 张；几乎无辅助信息 | 30分 + 2 BREAK | 10分 + 1 BREAK | 7分 |

其余有效参与者固定获得 1 积分。BREAK 奖励与难度无关：冠/亚固定 2 / 1 BREAK，季军仅得积分；有效参与（不含题主）满 3 人且冠军误差 ≤ 200 时才发放。
:::

::: tip B50 找内鬼
需先由群管发送 `开启mai猜歌`；与其它猜歌玩法及开字母 **同群互斥**。

- 系统随机抽取一位群友的 5 张 B50 卡片，并把其中一张的单曲 RA 改成错误值
- 45 秒内发送 `1`～`5` 作答，可以修改；速度排名按最终答案的提交时间计算
- 被抽中的题主不能提交有效答案，也不会进入奖励名单
- 答对第一名获得 10 积分 + 2 BREAK，第二名 6 积分 + 1 BREAK，第三名及后续答对者 3 积分
- 结算时标出内鬼卡片，并展示真实 RA 与被篡改后的 RA
:::

::: tip 极限二选一
需先由群管发送 `开启mai猜歌`；发 `极限二选一` 开局后，发送 `加入` 或 `参赛` 报名。

- 共 5 轮，每轮比较左右两首歌曲的随机指标，参赛者发送 `左` 或 `右` 作答
- 每轮按正确与否累计分数，结束时统一结算并展示揭晓图
- 揭晓图会在谱面定数旁明确标注：绿 Basic、黄 Advanced、红 Expert、紫 Master、白 Re:MASTER
- `重置二选一` 可由管理员或发起者强制结束当前对局
:::

::: tip 你想我猜（20 问猜曲）
需先由群管发送 `开启mai猜歌`；与其它猜歌玩法及开字母 **同群互斥**。

- 发送 `你想我猜` / `20问猜曲` 开局，Milk 心里想一首舞萌曲目
- 群友直接发送「是/否」类问题（如「是不是紫谱」「定数大于 14 吗」），由 LLM 理解并回答；也支持比较词、区间与分类/谱师/版本等条件
- 可随时直接猜曲名；输入 `查看已有信息` / `20问进度` 查看本局问答记录，`重置你想我猜` 强制结束
- 猜错不结束、超时公布答案；问得越少分越高，积分可叠加连击与加倍卡
:::
