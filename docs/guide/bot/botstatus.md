# 运行状态自检

当前服务状态：<FlashdutyStatus type="badge" />

发送 `botstatus`（别名 `bot状态`、`机器人状态`、`自检`）即可生成一张 Bot 运行状态图，
用于在「Bot 没反应 / 回复很慢」时快速判断是 Bot 本身、网络链路，还是上游服务出了问题。

维护模式期间其他功能会暂停，但 `botstatus` 和 `状态页` 仍可正常使用，方便随时查看维护进度。

## 状态图包含什么

### 运行概览

顶部胶囊汇总整体结论：

| 胶囊 | 含义 |
|---|---|
| 🟢 全部系统运行正常 | 所有已启用的探测都连通，状态页无异常 |
| 🟡 部分服务响应缓慢 | 有探测耗时超过 1.5 秒，或状态页报告性能下降 / 维护 |
| 🔴 N 项服务连接异常 | 有探测超时、连接失败或返回 5xx |

下方 8 个指标卡：

| 指标 | 说明 |
|---|---|
| 进程 CPU | Bot 进程近 10 秒的 CPU 占用（多核下可超过 100%） |
| 进程内存 | Bot 进程常驻内存，以及当前线程数 |
| 系统内存 | 服务器整体内存使用率 |
| 系统负载 | 1 / 5 / 15 分钟平均负载 |
| 事件循环延迟 | 消息分发主循环的滞后时间；持续偏高说明 Bot 正在被阻塞，消息会「卡住后一起发」 |
| 回复耗时 P50 / P95 | 最近 500 条回复从收到消息到提交 QQ 网关的耗时中位数 / 95 分位 |
| 已运行 | 本次启动至今的时长 |
| 网络自检 | 连通的探测项 / 已启用的探测项 |

指标卡左侧色条：绿色正常、橙色偏高、红色异常、灰色暂无数据（刚启动时需采样约 10 秒）。

### 今日消息

- **收到消息**：今日 00:00 起 Bot 收到的消息事件数（群聊 + 私聊）。
- **发出消息**：今日 Bot 成功发出的消息数（含文字、图片、文件）。
- **最忙时段**：今日收发总量最高的小时。
- **较昨日同期**：与昨天同一时间点之前的收发总量相比。
- **24 小时分布**：蓝色为收到、深色为发出，标出「现在」所在小时。
- **近 7 日收发总量**：每日收发合计，最右侧高亮为今天。

统计每分钟落盘一次，Bot 重启后会接续当天数据，保留最近 14 天。

### 网络自检

Bot 会并发探测下列服务，单项超时 5 秒：

| 探测项 | 分组 | 影响的功能 |
|---|---|---|
| BREAK 数据库 | 内部 | 签到、BREAK 计费、卡密、转账 |
| AWMC API | 内部 | 发票、账号预览、成绩 / 道具写入等账号功能 |
| AWMCNET | 内部 | AWMCNET 成绩同步 |
| AWMC 论坛 | 内部 | `qbind` 论坛 OAuth 绑定 |
| WMC API | 内部 | WMC 相关查询 |
| 状态页 | 内部 | 自动维护模式联动 |
| 水鱼查分器 | 外部 | 水鱼 B50、成绩查询与上传 |
| 落雪查分器 | 外部 | 落雪 B50、落雪上传 |
| 别名服务器 | 外部 | 曲目别名查询与同步 |
| QQ 开放平台 | 外部 | 官方 QQ 机器人收发消息 |

右侧显示往返耗时；`超时`、`HTTP 5xx` 或异常名表示该服务当前不可用，显示「未启用」表示该部署没有配置这项服务。
探测只发起轻量请求，不会读取或修改任何账号数据。

### AWMC 服务状态页

图片底部同步显示 [up.wmc.pub](https://up.wmc.pub)（由 FlashCat 提供）的整体状态、
进行中的故障 / 维护及计划维护。状态页发布 Bot 维护时，Bot 会自动进入维护模式，

## 常见判断

- **网络自检全绿、事件循环延迟很高**：Bot 进程繁忙，稍等片刻或联系管理员。
- **某个外部查分器红了**：对应的 B50 / 上传暂时不可用，可换另一个数据源。
- **AWMC API 红了**：账号类功能（发票、写入）暂停，请勿反复重试。
- **全部正常但仍不回复**：可能是 QQ 官方网关限流，或你有一个账号流程正在处理中（如发票），等它结束再试。

遇到持续异常时，请把状态图发到交流群反馈。
