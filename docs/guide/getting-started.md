## 🚀 三分钟上手 AWMC Bot

欢迎**添加 AWMC Bot**，或把它拉入你自己的群组，一起查分、排卡、猜歌～

👉 [点击添加 AWMC Bot](https://bot.q.qq.com/s/uYVc4fV6nK)

1. **添加机器人** — 点击上方链接添加，或由群主把 Bot 拉进自己的群；拉群后建议在群管理
   中允许 Bot 查看全部消息，猜歌、排卡等群功能才最顺手。
2. **同意用户协议** — 私聊或群内发送 `用户协议`，阅读网页后把完整确认词发回。
3. **绑定舞萌账号** — 发送 `mai绑定`，再把微信「舞萌DX | 中二节奏」二维码识别出的
   `SGWCMAID...` 发回即可。
4. **查分** — 发送 `b50` 查看成绩图；想绑定水鱼 / 落雪或开启 AWMC NET 免绑定查分，
   见 [使用说明](/guide/bot/intro)。
5. **群功能与群管理** — 猜歌、签到、排卡等直接在群里使用；群主 / 管理员发送 `群管理`
   可打开 [群管理后台](/guide/bot/group-console) 开关功能、看群数据、管排卡和天气。

更完整的指令清单见 [指令帮助](/guide/bot/advanced)，账号绑定、上传等调用细节见
[指令调用](/guide/bot/commands)。
