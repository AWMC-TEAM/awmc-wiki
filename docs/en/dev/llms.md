# 🤖 Ask AI & llms.txt

This site is LLM-friendly: you can ask the built-in AI, hand any page to ChatGPT or Claude in one click, or load a plain-text version of the docs in your own program or agent.

## ✨ Ask AI

Every page has an **✨ Ask AI** button in the bottom-right corner (doc pages also have one at the top). The assistant searches this wiki for passages related to your question, combines them with the page you are reading, and links the pages it used at the end of its answer.

::: warning Note
Answers are generated by AI from the docs and may be wrong. For billing, terms, bans and other important matters, the documentation itself is authoritative.
:::

If the built-in assistant is unavailable, the dialog offers "Ask in ChatGPT" / "Ask in Claude" buttons that carry your question and a link to the docs over.

## 📋 Copy page / Open in ChatGPT or Claude

The buttons above each doc page's title:

| Button | What it does |
| --- | --- |
| 📋 Copy page | Copies this page's Markdown source to the clipboard, ready to paste into any AI |
| 📄 View as Markdown | Opens the `.md` version of this page in a new tab |
| 💬 Open in ChatGPT / Claude | Opens the web chat with a "read this page" prompt prefilled |

## 📄 Files for LLMs

| URL | Contents |
| --- | --- |
| [`/llms.txt`](https://wiki.awmc.team/llms.txt) | Index of all docs, following the [llmstxt.org](https://llmstxt.org/) convention |
| [`/llms-full.txt`](https://wiki.awmc.team/llms-full.txt) | All (Chinese) docs merged into one plain-text file |
| Page URL + `.md` | Markdown source of a single page, e.g. [`/en/guide/bot/intro.md`](https://wiki.awmc.team/en/guide/bot/intro.md) |

The primary documentation is in Chinese; `llms-full.txt` contains the Chinese version, which modern LLMs read fine.
