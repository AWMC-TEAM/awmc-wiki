# 🤖 Ask AI & llms.txt

This site is LLM-friendly: ask the built-in AI, hand a page to DeepSeek, Doubao, Kimi, ChatGPT or Claude, or load plain-text documentation in your own program or agent.

## ✨ Ask AI

Every page has an **✨ Ask AI** button in the bottom-right corner (doc pages also have one at the top). The assistant searches this wiki for passages related to your question, combines them with the page you are reading, and links the pages it used at the end of its answer.

::: tip Scope
The built-in AI only answers practical questions directly related to AWMC and the services documented here. Unrelated topics, casual chat, roleplay, calculations, and general-purpose writing, translation or coding tasks are refused—even when mixed with a valid question or AWMC keywords. Asking how a command, pricing rule or chart-import procedure works is supported.

Requests are screened before an answer is generated. Failed or uncertain screening does not allow generation; it asks you to retry instead of calling your question off-topic. Neither explicit refusals nor screening failures offer external-AI fallback buttons. The assistant also does not generate an answer without available documentation.
:::

::: warning Note
Answers are generated by AI from the docs and may be wrong. For billing, terms, bans and other important matters, the documentation itself is authoritative.
:::

If the built-in assistant is unavailable, external AI shortcuts list DeepSeek, Doubao and Kimi first, followed by ChatGPT and Claude. Domestic-service shortcuts copy a prompt containing your question, the current page and the full-documentation link, then open the official site. Paste the prompt there.

## 📋 Copy page / Open in web AI

The buttons above each doc page's title and the “More options” menu:

| Button | What it does |
| --- | --- |
| 📋 Copy page | Copies this page's Markdown source, ready to paste into any AI |
| 📄 View as Markdown | Opens the `.md` version of this page in a new tab |
| 💬 Copy prompt & open DeepSeek / 豆包 / Kimi | Copies a “read this page” prompt and documentation link, then opens the official site; paste manually and log in if required |
| 💬 Open in ChatGPT / Claude | Retains the URL-prefill shortcuts; support depends on the destination website |

::: tip Copying and reading pages
Domestic-service shortcuts do not rely on unverified URL-prefill parameters and never submit a question automatically. If automatic copying is denied, the page displays the full prompt for manual copying instead of claiming success.

A working link does not guarantee an AI can read the page. If it cannot, return here, choose “Copy page” and paste the Markdown itself. External AI services are third parties; the built-in assistant's scope rules do not guarantee their behavior.
:::
